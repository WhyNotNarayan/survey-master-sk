# Survey Master SK Website

A professional land and drone surveying business website built with React, Node.js, and Supabase.

## Tech Stack
- **Frontend**: React (Vite), Bootstrap 5, AOS, Axios
- **Backend**: Node.js, Express, Supabase JS SDK
- **Database**: Supabase (PostgreSQL)
- **Storage**: Supabase Storage (for project images)

## Setup Instructions

### 1. Supabase Configuration
Go to your Supabase Dashboard and perform the following:

#### A. Create Tables
Run this SQL in the SQL Editor:
```sql
-- Projects Table
CREATE TABLE projects (
  id BIGINT GENERATED BY DEFAULT AS IDENTITY PRIMARY KEY,
  title TEXT NOT NULL,
  location TEXT,
  date DATE,
  description TEXT,
  image_url TEXT,
  created_at TIMESTAMPTZ DEFAULT NOW()
);

-- Contacts Table
CREATE TABLE contacts (
  id BIGINT GENERATED BY DEFAULT AS IDENTITY PRIMARY KEY,
  name TEXT NOT NULL,
  phone TEXT,
  message TEXT,
  created_at TIMESTAMPTZ DEFAULT NOW()
);
```

#### B. Setup Storage
1. Go to **Storage**.
2. Create a new bucket named `project-images`.
3. Set the bucket to **Public**.
4. (Optional) Set allowed mime types to `image/*`.

### 2. Environment Variables
1. Rename `.env.example` to `.env`.
2. Fill in your Supabase credentials:
   - `SUPABASE_URL`: Your project URL.
   - `SUPABASE_ANON_KEY`: Your anon/public key.
   - `SUPABASE_SERVICE_KEY`: Your service_role key (needed for backend file uploads).

### 3. Installation & Running

#### Server
```bash
cd server
npm install
npm run dev
```

#### Client
```bash
cd client
npm install
npm run dev
```

## Admin Access
The admin panel is hidden. To access it:
1. Go to the website.
2. **Click the logo "Survey Master SK" 5 times quickly** (within 3 seconds).
3. A login modal will appear.
4. Use the credentials set in `.env` (Default: `admin` / `surveymaster2024`).

## Features
- Full Project CRUD (Add/Edit/Delete projects with images).
- Contact form that saves inquiries to the database.
- Mobile-responsive design with professional aesthetics.
- Smooth scroll animations using AOS.
